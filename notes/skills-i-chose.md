# Skills I chose

Searched skills.sh on 2026-11-05 for: email marketing, email sequence, campaign plan, resend. Nothing has been installed. Install counts and GitHub stars are what the pages showed that day, and they will change.

## Use these

**For writing campaigns: `anthropics/knowledge-work-plugins`**
- Published by Anthropic, the company that makes Claude, and the repository has 34.8K GitHub stars.
- It has the two skills we need: `campaign-plan` (3.4K installs) and `email-sequence` (3K installs).
- Its install counts are modest, but the publisher and stars are strong. This is why install counts alone can mislead.

**For sending email: `resend/resend-skills`**
- Published by Resend, the email service we connect to later, so it should match how Resend works.
- Its main skill, `resend`, has 24.2K installs. The repository has 212 stars, which is low, but the official publisher matters more here.
- `resend/email-best-practices` (8.2K installs, 147 stars) is a useful extra from the same publisher.

## Avoid these

**`caffeinelabs/skills@extension-email-marketing`**
- 30.1K installs but only 2 GitHub stars. That gap means the install count tells us little about how many people trust it.
- It is also a poor fit: it was written as an extension for Caffeine AI, not for general email campaigns.

**`mbfinotti/sales-skills@sales-outbound-sequence`**
- 33.2K installs but only 3 GitHub stars, and skills.sh first saw it on 13 September 2026. That is a lot of installs in under two months.
- It is about cold outbound sales, not emailing people who joined a waitlist.

This doesn't prove either one is harmful or that its numbers are fake. It only means the numbers aren't enough reason to trust them.

## How I decided

Check these three things before installing any skill:

1. **Who publishes it?** Prefer the company behind the tool, or a well-known author.
2. **Do the GitHub stars fit the install count?** Installs can be faked or inflated. Thousands of installs with a handful of stars is a warning sign.
3. **Does it still exist, and does it do what you need?** Open its page and read the skill itself. Names change too: `coreyhaines31/marketingskills` (58.7K stars) renamed `email-sequence` to `emails` in its v2.0, yet the old name still shows up in search with 55.1K installs.
