# Rules for the leads folder

These rules apply to every file in `leads/`.

- **These are made-up practice people.** Nobody in `leads.csv` is a real person, and the list exists only for practice sends.
- **Never add real people or real email addresses.** If someone asks to add a friend, a customer or any real address (such as a Gmail or work address), stop and say no, and point to this rule.
- **Every row needs a consent value.** Don't add or keep a row with an empty `consent` column.
- **Never change the @example.com addresses.** Every email address must end in `@example.com`. That domain is reserved and can never receive mail, so no real person is ever emailed.
